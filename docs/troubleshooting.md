# Troubleshooting

Logs are at **Settings → Diagnostics → Open folder**. Set the log level to _Debug_ to see more detail.
Credentials are always redacted from logs.

| Symptom                                                    | Cause / fix                                                                                                                                                                                            |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `TLS certificate problem talking to host`                  | The registry uses a private or self-signed CA. Add the CA PEM in the registry's _Connection security_ section, or globally under Settings → Network. Use _Skip TLS verification_ only for lab setups.  |
| `host does not speak HTTPS`                                | The registry is plain HTTP. Turn on _Use plain HTTP_, or use an `http://` URL.                                                                                                                         |
| `Authentication failed …`                                  | Wrong username or token, an expired token (GCR access tokens expire after about 1 h), or missing scopes. See [Registry setup](registries.md).                                                          |
| `Access denied …`                                          | The credentials are valid but lack permission for that repository or action, for example push or delete.                                                                                               |
| _This registry does not allow listing repositories_        | `_catalog` is disabled. Type the repository name in the Explorer filter and press **Enter**, then pin it.                                                                                              |
| Delete fails with `UNSUPPORTED` / HTTP 405                 | The registry has deletes disabled (registry:2 needs `REGISTRY_STORAGE_DELETE_ENABLED=true`), or the provider doesn't support API deletes (Docker Hub).                                                 |
| _Docker is not running_ / _Docker engine not found_        | Start Docker Desktop or the daemon. For Colima, OrbStack, Rancher Desktop or Podman, make sure the docker context points to it (`docker context ls`), or set the endpoint in Settings → Docker engine. |
| `Permission denied on unix:///var/run/docker.sock` (Linux) | Add your user to the `docker` group (`sudo usermod -aG docker $USER`), then log out and back in. Rootless Docker uses `unix://$XDG_RUNTIME_DIR/docker.sock`.                                           |
| Pulled image has the wrong architecture                    | Choose the platform in the Pull dialog, or set Preferences → Default platform. _Auto_ matches the engine's os/arch.                                                                                    |
| `ssh://` docker context                                    | Not supported. Expose a `unix`, `npipe` or `tcp` endpoint instead.                                                                                                                                     |
| _Unlock with OS keychain_ is greyed out on Linux           | No secret service (GNOME Keyring or KWallet) is running. Install and unlock one, or keep using the master password.                                                                                    |
| ECR: `AWS: …` errors                                       | Check the region, the clock (SigV4 signatures are time sensitive) and the IAM permissions.                                                                                                             |
| Transfer interrupted                                       | Jobs that were running when the app quit are marked _Interrupted_. Press **Retry**. Already downloaded layers are reused from the cache.                                                               |
| macOS: "app is damaged / can't be opened"                  | The build is unsigned. Right-click → Open, or run `xattr -dr com.apple.quarantine "/Applications/Helix-X Docker Client.app"`.                                                                          |
| Linux AppImage won't start                                 | Run `chmod +x *.AppImage`. On Ubuntu 22.04 and newer, install `libfuse2`.                                                                                                                              |
